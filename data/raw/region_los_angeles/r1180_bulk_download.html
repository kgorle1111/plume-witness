Rule 1180 Historical Data Bulk Download

Share:

This page contains Rule 1180 historical data files available for download. The files are updated quarterly.

  • Rule 1180 Historical Data Bulk Download

The data files are categorized by three averaging duration:

  • 5 minute data

  • Rolling one hour data

  • Previous one hour data

Each data file will have data for all Rule 1180 monitoring stations with all the pollutants being measured by each station. All files are in comma separated variable (CSV) format that are compressed to save space.

Note: The files will contain a large number of rows and appropriate software that can handle this number of rows will be needed to work with the data.

Each table entry has the file name, linked to the file and the size of the (zipped) file.
